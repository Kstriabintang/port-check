API Documentation

Free, no key required. 100 live checks per IP per day. Base URL: https://portcheck.my.id

GET /api/check

Live-check a single proxy. Probes SOCKS5, HTTP CONNECT and SOCKS4; on success, also resolves the exit IP and country through the tunnel.

curl "https://portcheck.my.id/api/check?proxy=socks5://1.2.3.4:1080"
{
  "proxy": "1.2.3.4:1080",
  "status": "active",        // active | open | down
  "type": "SOCKS5",          // SOCKS5 | SOCKS4 | HTTP | -
  "country": "Singapore",    // only when active
  "exit_ip": "203.0.113.7",  // only when active
  "latency_ms": 245,
  "speed": "FAST"            // FAST | MEDIUM | SLOW | BAD
}

POST /api/check-bulk

Check up to 25 proxies in parallel. Send plain text (one proxy per line) or JSON {"proxies": [...]}. Each proxy costs 1 quota.

curl -X POST https://portcheck.my.id/api/check-bulk \
  --data-binary @my-list.txt
{
  "checked": 25,
  "invalid": ["bad-line"],
  "results": [ { "proxy": "...", "status": "active", ... } ]
  // sorted: active first, then open, then down — fastest first
}

GET /api/stats

Rollup of the latest scheduled full scan (runs every 2 hours via GitHub Actions).

curl "https://portcheck.my.id/api/stats"
{ "healthy_total": 76, "smtp_capable": 29, "by_country": { "United States": 44, ... } }

Field reference

FieldMeaning
statusactive = verified working proxy · open = port open but not a proxy · down = unreachable
typeConfirmed proxy protocol; - when the port isn't a proxy
serviceFor open ports: what's actually running there (e.g. https-web, squid)
latency_msTCP connect time from the nearest Cloudflare edge
speedFAST ≤ 1s · MEDIUM ≤ 3s · SLOW ≤ 6s · BAD > 6s

Limits & notes

  • Quota: 100 checks/IP/day (HTTP 429 when exceeded).
  • Outbound port 25 is blocked by Cloudflare — live SMTP tests are not possible here; SMTP data comes from the scheduled scanner.
  • Errors: {"error": "..."} with HTTP 400/404/429.
